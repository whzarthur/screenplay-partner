# 引导式剧本共创

通过一次一个问题，逐步挖掘作者的情绪、画面与创作意图，共同完成短片或连续短剧。

## 工作方式

作者描述情绪感受，AI 负责设计人物台词、动作与反应，再通过短场景试写校准。无需作者扮演角色或亲自写台词。

- 一次只问一个问题，已有信息不重复询问。
- 短片与连续短剧、时长和画幅由作者决定。
- 不主动询问发布平台、目标观众或真人/AI制作方式。
- 六类观众体验：共鸣、娱乐、感动、好奇与紧张、爽感与释放、启发与收获。
- 按故事机制选择公式，支持完整采用、局部借用或不采用。
- 成稿包含必要括号提示，并使用内附模板导出 HTML。

## 安装与使用

将本仓库文件放入本地技能目录的 `screenplay-partner` 文件夹，保持 `SKILL.md`、`agents`、`references` 和 `assets` 的相对位置。

默认目录：`~/.codex/skills/screenplay-partner/`。

调用示例：

```text
使用 $screenplay-partner 和我一起创作一个关于相爱却无法共同生活的短片。
```

也可以提供已有梗概或剧本，要求局部重写、台词改进或分集规划。
