# F01 · 五阶段目标推进（出售时间案例）

## 使用前先判断

这是目标驱动故事的组织工具，不是所有故事的统一标准。先从当前梗概或已有文本寻找实际证据：

- 人物是否有可理解的目标、欲望或需要处理的问题？目标可以细小或逐渐明确，不必是宏大任务。
- 主要进展是否来自人物行动与后果，而非主要依靠观察、氛围、并置或知识讲解？
- 阻碍能否自然促成新的选择、代价与局势变化？
- 关键行动及其后果是否符合用户想要的情绪体验、节奏与结局？完整套用是否反而需要捏造危机或拉长故事？

采用方式和对用户的说明遵循 [formula-router.md](../formula-router.md)。生活观察、氛围并置或知识讲解为主的作品通常不宜完整采用；也可只用于自然符合上述条件的支线。不要为满足条件而先编造危机。

## 采用后如何组织

| 阶段 | 要解决的创作问题 | 边界 |
|---|---|---|
| 激励事件 | 什么变化让人物开始处理这个问题？为什么从此刻讲起？ | 是因果起点，不必成为影片第一镜；倒叙可先展示后果再回溯 |
| 进展纠葛 | 人物期待什么，行动带来什么偏差或代价，如何促成下一步？ | 可以失败，也可以成功后出现新代价；不要求每次都失败或靠巧合出事 |
| 危机 | 原来的办法为何失效？人物必须面对什么选择或局限？ | 重点是选择压力，不是堆砌苦难；不强求全片情绪最低点 |
| 高潮 | 什么关键行动回应了核心冲突？ | 可以安静、失败、拒绝改变或离开，不要求打斗、反转或正向成长 |
| 结尾 | 行动留下什么后果，是否兑现用户选择的余味？ | 可以留白、团圆或悲剧，不强制升华、哲理台词或再次反转 |

进展纠葛可用“想要 A → 采取行动 → 得到意外的 B 或带代价的 A → 重新选择”推演。每次变化应有因果或充分铺垫，而非为维持冲突让人物突然失智。

这些阶段是功能，不是五场戏或五个等长时间段；可交叠、压缩或跨多个场景，不规定爆点秒数和镜头数量。使用后若某节点只能靠无关事件填满，应返回适用性判断，改成局部借用或其他结构，而非继续硬填。

悬疑还需单独安排人物与观众何时获得信息；连续短剧要分别判断整季、单集和支线，不在每集机械重复同一套低谷与翻盘。情感片允许以小而累积的关系后果推进，保留真实亲密与暂时好转，不把人物写成制造障碍的工具。

## 验收与来源

大纲完成后检查：每个节点是否由人物与前因促成，高潮是否回应主线，结尾是否保留可信后果，以及采用公式是否挤掉用户想要的细节。发现问题时修改具体段落或换结构，不用“节点齐全”证明故事有效。

本工具整理自用户提供的《AI短片拆解_视频转写全文.md》及本次讨论。原视频、点赞量与作者身份未独立核实；不继承“爆款保证”“苦难越多越好”“高潮必然成长”等绝对化推断。技能使用不依赖原 Downloads 文件。
