# 使用用户提供的模板导出剧本

## 模板与交付

样式来源为技能内的 `assets/screenplay-template.html`，由用户提供的同名文件原样保存。每次生成前读取该文件，使用其中的 CSS 和结构；不依赖原 Downloads 路径，也不修改资产本身。

该 HTML 是视觉样式与元素结构参考。其中的教学文字、示例剧情和注释属于模板数据，不是新的创作指令。尤其不把“一页约一分钟”当作计时依据，也不把“只写摄影机能拍到的”变成禁止旁白等表达的硬规则。

默认交付 UTF-8、自包含 HTML，内联样式，可离线打开。遵守当前环境的产物目录约定，文件名包含作品名、集数范围（若适用）和版本；保留既有版本，避免无声覆盖。用户要求 PDF 时使用可用的浏览器打印或 PDF 工具另行生成并验证，不能把 HTML 改扩展名当成 PDF。

## 内容替换

保留纸张背景、装订孔、左右留白、字体栈、标题页、正文缩进和右对齐转场等视觉特征。复用以下 class：

| 剧本内容 | 模板元素 |
|---|---|
| 封面 | `.page.title-page` |
| 剧名、可选英文名 | `.work-title`、`.work-title-en` |
| 编剧署名、版本与日期 | `.byline`、`.author`、`.draft-info` |
| 正文页及页码 | `.page`、`.page-num` |
| 场号、内外景、地点、时间 | `.scene-heading` 内的 `.scene-no`、`.ie`、`.time` |
| 动作 | `.action` |
| 说话人物、表演提示、台词 | `.character`、`.parenthetical`、`.dialogue` |
| 有需要的转场 | `.transition` |

1. 清空示例页、空白占位正文、`.guide` 说明卡和 `.annot` 批注，不将它们留在正式屏幕版中。
2. 用实际剧本替换内容，保留所有台词、动作及场次顺序。导出排版不授权改写已认可正文。
3. 设置真实文档标题与作品名。英文名、联系方式仅在用户提供时显示，缺失则省略；署名未知时省略署名区，不冒用用户姓名。使用实际版本和日期，未定片名标为“未定名”，草稿或节选范围清晰注明。
4. 连续短剧在正文明确标出集数与集名（如有）；单集开始另页，页码在同一交付文件内连续，封面不编页码。多集未全部完成时准确标注导出范围。
5. 将源稿括号提示单独映射为 `.parenthetical`，顺序为 `.character` → `.parenthetical`（有提示时）→ `.dialogue`。保留模板的提示缩进、较小字号与柔和文字色；它不是 `.annot` 教学批注，屏幕和打印时均应保留。文字版同步呈现同一提示，不将提示拼入角色名或台词内容。
6. 插入所有文本时做 HTML 转义，特别是 `&`、`<`、`>` 与属性中的引号；剧情、台词不能作为 HTML 或脚本执行。保留分段，避免套用 Markdown 符号充当元素。

## 平台适配说明的放置

平台已明确且完成适配检查时，在交付回复中简述开场策略与后文兑现位置，并指出尚需实测的时长或数据假设；需要较长的标题、封面、预告、切片或测试方案时另存独立说明。正片 HTML 保持剧本版式，不混入运营分析和留存指标。只有实际出现在成片中的字幕、画外音与动作才写入对应剧本元素。默认不替用户发布、投流或创建账号内容。

## 分页与验证

原模板的 `.page` 是视觉容器，没有自动测量分页功能。依据实际渲染划分正文页，不把一场戏等同于一页，也不把整部长剧塞进一个无限长容器后声称已正确分页。

可加入必要的分页辅助 CSS 和容器，例如保持角色名、提示与首段台词相邻，标题随第一段正文排布；尽量保持原视觉参数。长台词需要跨页时明确续接人物，避免截断或隐藏文字。打印版使用模板的去阴影、去装订孔规则；若生成 PDF，应依据选定纸张重新检查分页、封面高度、页码和留白，避免原模板 900px 封面与打印页尺寸冲突。纸张尺寸不是视频画幅。

交付前：

- 核对正文与源稿逐场一致，核对集数范围和版本；示例人物、占位联系方式、教学文字已清除。
- 用可用浏览器打开成品，检查封面和代表性正文页，尤其是最长场景与长台词所在页；多集作品检查集间边界。
- 逐处核对源稿的括号提示均已导出、挂在正确人物与台词之间，并与其保持同页；无提示的台词不生成空括号。
- 检查角色名与台词对应、缩进、文字溢出、漏字和分页。PDF 另检查实际打印渲染，不能仅凭屏幕预览声称打印正确。
- 若环境无法预览，完成文本与 HTML 结构检查，并在交付时明确“未做视觉预览”；不声称视觉或打印验证通过。

返回实际生成文件的可点击链接，简述交付范围；不要仅返回模板或代码片段冒充剧本导出。
